# chatslaughter

Нативное приложение для массовой очистки чатов Telegram на macOS.
SwiftUI + TDLib. Сессия хранится локально, сервера приложения нет.

**Текущий статус — версия для разработки.** Демо и жизненный цикл локальной
TDLib проверены. Вход и удаление на реальном аккаунте требуют отдельной проверки
на тестовом аккаунте; стабильный публичный релиз пока не готов.

## Запуск

```sh
brew install tdlib
./scripts/test.sh
./scripts/build-app.sh
open dist/chatslaughter.app
```

Для проверки интерфейса нажми «Посмотреть демонстрацию». Для своего аккаунта
получи API ID и API Hash на https://my.telegram.org/apps и введи их в приложении.
Коды входа и пароль вводятся только в приложение.

## Работа с чатами

1. Выбери тип чатов в боковой панели. При необходимости используй поиск,
   архив или фильтр без сообщений за последние 90 дней.
2. Выдели строки через ⌘/⇧ или выбери все видимые чаты кнопкой в панели.
3. Нажми «Просмотреть действия…» или ⌘↩.
4. Проверь список и подтверди выполнение.

Личные чаты удаляются только у тебя. Для групп и каналов выполняется выход;
оставшаяся запись удаляется, если это разрешает TDLib. Избранное, секретные
чаты и группы/каналы, которыми ты владеешь, защищены.

«Остановить» отменяет оставшуюся очередь после обработки текущего чата.
Тайм-аут означает неизвестный результат: проверь Telegram перед новой попыткой.
Ошибки и частичные результаты показаны отдельно для каждого чата.
